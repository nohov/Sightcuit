# Circuit v1 — Live Test (MacBook)

## Setup (once)

```sh
cd <repo root>
python3 -m venv .venv
.venv/bin/pip install torch torchvision
.venv/bin/pip install -r training/requirements.txt
.venv/bin/pip install opencv-python-headless  # or opencv-python for display
```

Add your Gemini key to `.env` in the repo root:
```
GEMINI_API_KEY=your-key-here
```

## Run live

```sh
set -a; . ./.env; set +a

.venv/bin/python -m recognition.live_runner \
  evaluation/live_predictions.jsonl \
  --weights training/weights/circuit_v1_best.pt \
  --config recognition/circuit_v1_model.json \
  --allow-upload --camera 0 --device mps
```

Use `--device cpu` if MPS causes issues.

## What to look for

| Color | Means |
|---|---|
| Yellow box | Detector saw it, Gemini labelling... |
| Green box | Confirmed + named |
| No box | Model missed it |

## Classes this model knows

| Class | mAP50 |
|---|---|
| board (Arduino + breadboard) | 0.948 |
| red_led | 0.934 |
| resistor | 0.908 |
| blue_wire (USB cable) | 0.820 |
| switch | 0.817 ⚠️ weakest |
| wire (jumper wires) | 0.683 ⚠️ weakest |

## Known gaps

- Switch trained on only 101 images, 23 were skipped during auto-labeling
- Wire combines black/white/yellow — may confuse at distance
- Labels generated by Grounding DINO (auto), not human-verified
- Real-world accuracy may differ from the 0.852 mAP50 score
