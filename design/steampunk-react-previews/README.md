# ScavScrap · Steel & Steam React previews

Four visual studies inspired by the [SBUHacks Steel and Steam site](https://hack.sbcs.io/) and the owner's steampunk references. **Steam Command** adds a central work area and floating instrument panels, following the feel of the owner's latest cinematic reference. The artwork is original CSS and SVG; the supplied stock images and film still are not included.

Open `index.html` in a browser with internet access, or serve this folder locally. Use the buttons or `?theme=command`, `?theme=stage`, `?theme=ledger`, and `?theme=night` to switch previews. React 18 is loaded from a pinned CDN URL for the preview only; nothing is installed in this repository.

These are **design mockups**. Boxes and class labels are illustrative UI text, not YOLO predictions. The current repository has no React application or live detector feed. Screenshots in this folder are rendered from the React preview.
