1. Glasses + Meta AI app (on your phone)
- Update the glasses firmware: Meta AI → Devices → gear icon → General → About → Version.
- Turn on Developer Mode: Meta AI → Settings → App Info, tap the version number 5 times, then turn it on.

2. Mac
- Install Xcode 26.4 or later, then sign in with your Apple ID under Xcode → Settings → Accounts. A free account works.
- Copy the branch over: git push -u origin feat/glasses-relay here, then pull it on the Mac. I haven't pushed, so tell me if you want me to.
- Follow app/ios/README.md → "Create the Xcode project", steps 1–5. That's a new SwiftUI app plus Meta's package, https://github.com/facebook/meta-wearables-dat-ios.
- Build it. Expect a few compile errors because the code has never been built. Paste them to me and I'll fix them.

3. Simulator test (optional, no glasses needed)
- Add a short clip you're allowed to use as mock-feed.mp4, run in the simulator, and tap "Use mock glasses".

4. Laptop
- Start the relay:
set -a; . ./.env; set +a
.venv/bin/python -m recognition.live_runner evaluation/glasses_predictions.jsonl \
  --weights /absolute/path/to/yolov8l-worldv2.pt --allow-upload --listen 0.0.0.0:8765
- Copy the token it prints.
- Find the laptop's Wi-Fi IP with ip addr (look for an address like 192.168.x.x).
- Quick check before using the phone:
curl -H "Authorization: Bearer <token>" --data-binary @<some-permitted>.jpg http://localhost:8765/frame
  It should print the tracks as JSON.

5. iPhone
- Plug it in, choose it in Xcode, and press Run. On a free account the app expires after 7 days, so you'll re-run it then.
- On first launch, trust the developer certificate: Settings → General → VPN & Device Management.
- In the app:
  a. Enter <laptop-ip>:8765 and the token.
  b. Tap "Connect glasses in Meta AI" and approve the app there.
  c. Tap "Start streaming".
  d. Allow local network access when iOS asks.

6. Check it works
- Boxes should appear on the phone, and new lines should land in evaluation/glasses_predictions.jsonl.
- If the stream gets stuck on waitingForDevice, the usual causes are the glasses being out of range, Developer Mode being off, or the hinges being closed.
